The funniest error message a kitchen toaster would show its owner, in one line of at most 120 characters. It reads like a real appliance message — an error code, a status update, then an instruction — and the joke is the reversal in the middle: good news, then the toaster calmly reporting its own fire as if it were a routine status update.

> Error 004: Your toast is ready. It is also on fire. Please remain calm and open a window.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
